# پایشگر سخت‌افزار اندروید

اپلیکیشن فارسی برای نمایش زنده اطلاعات سخت‌افزار، بدون نیاز به روت.

## امکانات
- مصرف، کل و حافظه آزاد RAM از Android ActivityManager
- مصرف کلی CPU از /proc/stat، فقط در صورت امکان خواندن
- فرکانس CPU در صورت دسترسی به sysfs
- فرکانس و بار GPU فقط در صورت افشای این داده‌ها توسط کرنل
- دمای باتری و حسگرهای حرارتی در صورت دسترسی
- به‌روزرسانی تقریباً هر یک ثانیه
- تم روشن، تاریک و هماهنگ با سیستم
- رابط فارسی و راست‌چین

## ساخت APK
نیازمند JDK 17 و Android SDK Platform 35:
`gradle assembleDebug`

خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## محدودیت‌ها
اندروید و سازنده گوشی ممکن است دسترسی به برخی فایل‌های sysfs یا /proc را محدود کنند. در این حالت شاخص مربوطه نمایش داده نمی‌شود و مقدار ساختگی جایگزین نمی‌شود. برنامه هیچ مجوز روت یا مجوز خطرناکی درخواست نمی‌کند.
