# Shayan Phone
اپلیکیشن یکپارچه تلفن و مخاطبین با رابط Material 3.

نسخه اولیه شامل شماره‌گیر، تماس خروجی، فهرست مخاطبین، جست‌وجو، تاریخچه تماس‌ها و درخواست نقش Default Dialer است.

## آزمایش دسترسی‌پذیری در نسخه 2.4.0

این نسخه یک سرویس آزمایشی دسترسی‌پذیریِ اختیاری دارد که فقط تغییر وضعیت پنجره رابط تماس را در چند بستهٔ شناخته‌شده ثبت می‌کند. محتوای صفحه، شماره‌ها، متن‌ها و صدای تماس خوانده یا ذخیره نمی‌شوند. فعال‌سازی فقط با اقدام دستی کاربر در تنظیمات اندروید انجام می‌شود.

این سرویس مسیر دسترسی به صدای تماس نیست و قابلیت ضبط دوطرفه ایجاد نمی‌کند.

## ضبط تماس
مجوز میکروفون یا نقش برنامه پیش‌فرض به‌تنهایی مجوز ضبط صدای دوطرفه نیست. Android عمومی API قابل اتکایی برای دریافت صدای دوطرفه تماس به اپ‌های عادی ارائه نمی‌کند. دکمه ضبط زمانی اضافه و فعال می‌شود که سازنده یک API رسمی و مجاز ارائه کند؛ در غیر این صورت نمایش دکمه‌ای که عملاً کار نمی‌کند گمراه‌کننده است.
