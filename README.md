# پایشگر سیستم

اپلیکیشن اندرویدی فارسی برای نمایش اطلاعات سخت‌افزار بدون روت.

## قابلیت‌ها
- بار CPU از طریق /proc/stat، در صورت دسترسی
- فرکانس CPU در صورت دسترسی به sysfs
- ظرفیت، مصرف و حافظه آزاد RAM از API عمومی اندروید
- فرکانس و بار GPU فقط در صورت ارائه توسط سیستم
- دمای باتری و حسگرهای حرارتی در صورت دسترسی
- تم روشن، تاریک و مطابق سیستم
- تازه‌سازی تقریباً هر یک ثانیه

## سازگاری
حداقل Android 8.0 (API 26). هدف، سازگاری با Android 10 و نسخه‌های جدیدتر است.

## ساخت APK
از بخش Actions مخزن، workflow با نام Android APK را اجرا کنید. فایل خروجی با نام SystemMonitor-debug در بخش Artifacts قرار می‌گیرد.

## دسترسی‌ها
برنامه هیچ مجوز خطرناک، دسترسی روت یا سرویس پس‌زمینه‌ای درخواست نمی‌کند. برخی شاخص‌ها بسته به کرنل و محدودیت‌های امنیتی دستگاه ممکن است در دسترس نباشند؛ در این حالت آن شاخص نمایش داده نمی‌شود.
