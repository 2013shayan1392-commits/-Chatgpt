# تبلیغ‌یار

مینی‌اپ سفارش تبلیغات کانال‌های ایتا. کاربر تعداد بازدید را انتخاب می‌کند، متن و لینک کانال و تصویر رسید را می‌فرستد؛ بررسی پرداخت و انتشار توسط مدیر به‌صورت دستی انجام می‌شود.

## امکانات
- بازه سفارش ۱٬۰۰۰ تا ۲۰۰٬۰۰۰ بازدید با گام ۱٬۰۰۰
- تعرفه اولیه ۹۰٬۰۰۰ تومان برای هر ۱۰٬۰۰۰ بازدید
- ثبت رسید تصویری و ذخیره امن خارج از پوشه عمومی
- ذخیره تعرفه زمان سفارش؛ تغییر تعرفه فقط روی سفارش‌های بعدی اثر دارد
- ورود مدیر، بررسی رسید، تغییر وضعیت و تنظیم تعرفه
- اعتبارسنجی امضای initData ایتا در سمت سرور

## نصب
نیازمند Node.js 20+ و PostgreSQL:
1. دیتابیس را بسازید و `db/schema.sql` را اجرا کنید.
2. `.env.example` را به `.env` کپی کرده و مقادیر واقعی را فقط روی سرور تنظیم کنید.
3. `npm install`، سپس `npm test` برای اجرای آزمون‌های پایه و در پایان `npm start` را اجرا کنید.
4. دامنه HTTPS را در تنظیمات مینی‌اپ ایتا ثبت کنید.

در اولین راه‌اندازی، اگر `ADMIN_USERNAME` و `ADMIN_PASSWORD` تنظیم شده باشند، حساب مدیر ساخته می‌شود. تغییر رمز محیطی پس از ایجاد حساب، هش موجود در دیتابیس را تغییر نمی‌دهد؛ برای تغییر رمز، هش جدید را با bcrypt تولید و در جدول admins به‌روزرسانی کنید.

## نکات امنیتی
- توکن ایتا، رمز مدیر و `.env` را هرگز در GitHub قرار ندهید.
- برای تولید از HTTPS و SESSION_SECRET تصادفی حداقل ۳۲ نویسه استفاده کنید.
- رسیدها فقط از مسیر احراز هویت‌شده مدیر قابل مشاهده‌اند.
- قبل از انتشار عمومی، ورود واقعی ایتا، اتصال دیتابیس و سیاست CSP را در دامنه نهایی آزمایش کنید.
- این مخزن سورس‌کد است و به‌تنهایی سرویس زنده ایجاد نمی‌کند؛ هاست HTTPS و PostgreSQL لازم است.
