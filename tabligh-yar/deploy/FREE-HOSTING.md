# راه‌اندازی رایگان تبلیغ‌یار با Supabase Edge Functions

نسخه آنلاین تبلیغ‌یار روی همان پروژه Supabase اجرا می‌شود؛ سرویس مینی‌اپ، API، PostgreSQL و فضای رسیدها در یک پروژه قرار دارند. در این معماری به میزبان Node.js جداگانه نیاز نیست.

## آدرس‌های پروژه

- مینی‌اپ: https://nvegaokijnrknjwctkbt.supabase.co/functions/v1/tabligh-yar
- سلامت API: https://nvegaokijnrknjwctkbt.supabase.co/functions/v1/tabligh-yar/api/health
- مدیریت secrets: https://supabase.com/dashboard/project/nvegaokijnrknjwctkbt/functions/secrets

## Secrets لازم

در پنل Supabase به Edge Functions → Secrets بروید و این سه مقدار را اضافه کنید:

- `EITAA_BOT_TOKEN`: توکن محرمانه بات/برنامه ایتا که از مسیر رسمی ایتا دریافت شده است.
- `ADMIN_USERNAME`: نام کاربری مدیر.
- `ADMIN_PASSWORD`: رمز عبور قوی و یکتا برای مدیر.

این مقادیر را فقط در پنل secrets وارد کنید؛ آن‌ها را در GitHub، کد مرورگر یا گفتگو قرار ندهید. کلیدهای Supabase به‌صورت خودکار در محیط Edge Function موجود هستند. تابع از کلید سمت سرور استفاده می‌کند و هیچ کلید محرمانه‌ای به مرورگر نمی‌فرستد.

پس از ذخیره secrets، نیازی به deploy مجدد تابع نیست. حساب مدیر در اولین تلاش ورود، در جدول admins ایجاد می‌شود.

## ساختار داده و امنیت

- دیتابیس PostgreSQL و چهار جدول اصلی آماده‌اند.
- RLS روی جدول‌های public فعال است و سیاست عمومی برای خواندن/نوشتن سفارش‌ها ایجاد نشده است.
- bucket رسیدها خصوصی است و فقط مدیر احراز هویت‌شده از API می‌تواند رسید را دریافت کند.
- محدودیت رسید ۵ مگابایت و فرمت‌های JPEG، PNG و WebP است.
- احراز هویت کاربر با اعتبارسنجی امضای initData ایتا در سمت سرور انجام می‌شود.
- نشست‌ها با کوکی HttpOnly و محافظت CSRF نگهداری می‌شوند.
- `verify_jwt=false` برای Edge Function به این دلیل تنظیم شده که خود تابع احراز هویت اختصاصی ایتا و مدیر را انجام می‌دهد؛ مسیرهای مدیریتی بدون نشست معتبر قابل استفاده نیستند.

## بررسی پس از افزودن Secrets

1. آدرس سلامت باید پاسخ `{"ok":true,"database":"connected"}` بدهد.
2. مینی‌اپ را در مرورگر باز کنید تا صفحه و محاسبه تعرفه بارگذاری شوند.
3. پس از ثبت توکن ایتا، مینی‌اپ را از داخل ایتا باز کنید و ورود را آزمایش کنید.
4. با اطلاعات مدیر وارد پنل شوید.
5. یک سفارش آزمایشی ثبت و رسید را از پنل مدیر مشاهده کنید.

## محدودیت پلن رایگان

Supabase Free سهمیه و محدودیت دارد و ممکن است پروژه کم‌فعالیت را پس از مدتی متوقف کند. قبل از استفاده واقعی، وضعیت سهمیه و پشتیبان‌گیری را در داشبورد کنترل کنید. هیچ ارتقای پولی یا روش پرداختی برای این راه‌اندازی فعال نشده است.
